# ZATHURA — دليل المشروع التفصيلي

**NASA Space Apps Challenge 2026 · The Next Frontier**
فئة: **Junior Astronaut Mission Trainer**

مشروع واحد، بوابة واحدة، **وضعا لعب** — بنفس الهوية البصرية ونفس الخطوط ونفس قائد المهمة.

## ١. بنية المستودع

```
Zathura_NASA_space_app_ZC/
├── index.html                 صفحة المشروع (GitHub Pages) — عربي/إنجليزي
├── play/                      ★ حزمة اللعب الجاهزة (تُنسخ كما هي وتعمل أوفلاين)
│   ├── index.html             البداية المشتركة — اختيار الوضع
│   ├── game1.html             الوضع ١: ZATHURA Outpost — محاكي القيادة العليا
│   └── game2.html             الوضع ٢: Odyssey · Survive — منظور أول 3D
├── src/                       مصدر الوضع ١ (١٠ وحدات + styles.css)
├── build.js                   src/ ← play/game1.html (يزيل كتل @QA)
├── tools/verify-build.js      إثبات أن game1.html مطابق للمصدر بايت ببايت
├── data/donki/                أرشيف أحداث مايو ٢٠٢٤ (DONKI)
├── docs/                      المرجع العلمي (١٥ سيناريو) + هذا الدليل
└── assets/                    لقطات، أيقونة، ملفات صفحة المشروع
```

**للمحكّم:** افتح `play/index.html`. لا خادم، لا تثبيت، لا إنترنت.

## ٢. الوضعان

| | الوضع ١ — محاكي القاعدة | الوضع ٢ — أوديسي: مهمة البقاء |

| اللعبة | ZATHURA Outpost v3.3.0 «العالم الحي» | Odyssey: Survive — من الإطلاق للهبوط |

## ٣. البناء

**الوضع ١ (من هذا المستودع):**

```bash
node build.js            # src/ → play/game1.html، مع إزالة أدوات الاختبار
node build.js --dev      # نفس البناء مع إبقاء كتل @QA-BEGIN/@QA-END محليًا
node tools/verify-build.js   # يتأكد أن الملف المرفوع = ناتج البناء
```

> أدوات الاختبار (`window.__completeAll`, `Return.skipTo`, `Board`, …) محصورة في
> المصدر بين `@QA-BEGIN` و `@QA-END`، ويُزيلها البناء الافتراضي — فلا تصل للاعب
> ولا للمحكّم. CI (`.github/workflows/verify.yml`) يعيد البناء ويقارن مع كل push.

**الوضع ٢:** بُني أصلًا بـ React 19 + TypeScript + Vite مع `viteSingleFile`،
وناتجه `play/game2.html` (كل الأصول مضمّنة base64). المصدر ليس في هذا المستودع.

## ٤. البيانات العلمية

- ثوابت دعم الحياة: NASA ECLSS · **BVAD 2022**
- الإشعاع: سقف **٦٠٠ mSv** (NASA STD-3001) · سطح المريخ **0.64 mSv/يوم** · العبور **1.84 mSv/يوم** (RAD/MSL)
- الطقس الفضائي: **DONKI** — مايو ٢٠٢٤ (أقوى عاصفة في ٢٥ سنة): `CME 85 · FLR 135 · GST 4 · Kp 9.0 · SEP 14`
- الوحدة والقيود: انظر [`../SOURCES-AUDIT.md`](../SOURCES-AUDIT.md)

كل رقم في اللعبتين إما قيمة NASA منشورة أو تقدير لعبة مكتوب صراحةً.
الأرقام **محاكاة تعليمية** مبنية على قيم منشورة، وليست قياسات حيّة.

ZATHURA مشروع تعليمي غير رسمي وغير ربحي. **لا يمثل NASA ولا أي وكالة حكومية،
